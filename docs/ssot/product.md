# Product SSoT

## 目的

TPP-2M式によるIMFP計算を、次の3つの入口から同一の計算coreで提供する。

1. 非対話CLI: スクリプト、研究ノート、CIから呼び出せる。
2. TUI: Lazygit風の分割ペインで、材料パラメータを編集しながら計算と両対数グラフを確認できる。
3. WASM: Webブラウザから同じcore計算を呼び出せる。

## MVP

MVPは次を満たす。

- Rust workspaceで `core`, `cli`, `tui`, `wasm` を分離する。
- `core` が単点計算とエネルギースイープを提供する。
- CLIが単点計算とスイープをJSON/CSVで出力できる。
- TUIがLazygit風レイアウト、数字フォーカス、Vim操作、両対数グラフを提供する。
- WASMがブラウザ向けに単点計算とスイープAPIを公開する。
- 古典学派TDDで実装し、workspaceラインカバレッジ80%以上を維持する。

## 非目標

MVPでは次を行わない。

- NIST等の外部データベースとのオンライン連携。
- 物質プリセットの網羅的DB化。
- 測定データへの自動フィッティング。
- GUIデスクトップアプリ。
- TPP-2M以外のIMFPモデルの実装。ただし将来拡張のため、`core` のAPI名はモデル境界を意識する。

## ユーザー像

- XPS/AESの初期解析でIMFPを素早く見積もりたい研究者。
- 実験ノートやスクリプトから同じ計算を再利用したい開発者。
- Webページ上でTPP-2M計算フォームを作りたい開発者。

## ユースケース

### UC-1: 単点計算

ユーザーはエネルギー、密度、分子量、価電子数、バンドギャップを指定し、IMFPをnmで得る。

受け入れ条件:

- 同じ入力に対してCLI/TUI/WASMの結果が一致する。
- 既定表示はnm。
- JSON出力には入力、係数、中間値、結果、警告を含める。

### UC-2: エネルギースイープ

ユーザーはエネルギー範囲と点数を指定し、エネルギーごとのIMFPを得る。

受け入れ条件:

- 線形または対数間隔のサンプリングができる。
- 範囲外または不正点は警告として返す。
- CSV出力では列名が固定される。

### UC-3: TUIで探索

ユーザーはTUI上で材料パラメータを編集し、グラフと結果表を見ながら探索する。

受け入れ条件:

- `1`〜`5` でペインフォーカスを移動できる。
- `h/j/k/l` などのVim風操作が使える。
- グラフは横軸 `Electron Energy / eV`、縦軸 `IMFP / nm` の両対数表示である。
- 計算エラーはクラッシュではなくメッセージペインに出る。

### UC-4: Webから呼び出し

Web開発者は `wasm-pack` 生成物をブラウザに読み込み、単点計算またはスイープ計算を呼ぶ。

受け入れ条件:

- JS側からJSON互換の入力で呼べる。
- エラーはJS例外またはResult相当として説明可能な形で返る。
- coreの計算ロジックはWASM crateに複製しない。

## 品質特性

| 項目 | 基準 |
|---|---|
| 正確性 | `docs/ssot/calculation.md` の式・単位・テストベクトルに一致する。 |
| 再現性 | 同一入力はOS/入口に依らず同一結果になる。 |
| テスト容易性 | `core` とTUI reducerは副作用なしでテストできる。 |
| 移植性 | Linux/macOS/WindowsのCLI/TUI、ブラウザWASMを対象にする。 |
| 保守性 | UI層に計算式を置かない。 |
| 可観測性 | JSON出力とエラーで中間値・警告を確認できる。 |
