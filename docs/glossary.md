# Glossary

| 用語 | 意味 |
|---|---|
| TPP-2M | Tanuma-Powell-Penn 2 Modified。電子の非弾性平均自由行程を推定する経験式。 |
| IMFP | Inelastic Mean Free Path。非弾性平均自由行程。 |
| E | 電子運動エネルギー。単位は eV。 |
| λ | IMFP。内部式ではÅ、ユーザー向け既定出力では nm。 |
| ρ | 密度。単位は g/cm³。 |
| M | 原子量または分子量。単位は g/mol。 |
| Nv | 原子または分子あたりの価電子数。 |
| Eg | バンドギャップ。単位は eV。金属では0 eV。 |
| Ep | 自由電子プラズモンエネルギー。単位は eV。 |
| SSoT | Single Source of Truth。実装判断の正本。 |
| 古典学派TDD | Detroit/classical style TDD。実オブジェクト中心、モックを最小限にするTDD。 |
| Lazygit風UI | 左右または上下に複数ペインを置き、数字キーやVim風操作でフォーカス移動するターミナルUI。 |
| reducer | イベントと状態から次状態を返す純粋関数。TUIテストの主対象。 |
